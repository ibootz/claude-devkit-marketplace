# ruanyf-document-style-guide — 中文技术文档写作规范

把阮一峰《中文技术文档的写作规范》打包成按需加载的 skill：写或改中文技术文档时，按这套规范检查标题层级、字间距、句子与段落、数值、标点符号与文档体系。

## 一句话用法

> 写中文 README、方案文档、教程时，让 Claude 按阮一峰规范来写或做风格检查。

## 这个 skill 干什么

`skills/ruanyf-document-style-guide/SKILL.md` 即规范全文，**原样收录自上游，未做任何改写**（用户要求保留原文以便自行调整）：

- **标题**：四级层级与四条结构原则（层级跳跃、孤立编号、重名、四级标题慎用）
- **文本**：中英文之间留半角空格、长句上限、肯定句优先、主动语态、英文处理六条
- **段落**：一段一主题、中心句前置、不超过七行
- **数值**：半角数字、千分号、货币、数值范围、「增加了/增加到」之辨
- **标点符号**：全角标点、顿号并列、引号层级、省略号、破折号、连接号
- **文档体系**：软件手册的推荐结构与文件名规则
- **参考链接**：十一份同类中文风格指南出处

## 触发方式

安装本插件后，说「按阮一峰规范写/检查这篇文档」「这篇中文文档有什么风格问题」「用中文技术文档规范过一遍」即可触发；技能 description 较短，未命中时可直接点名技能名。
