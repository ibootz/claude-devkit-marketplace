# 软件、业务与数据图型细分

SKILL.md 主索引已定到大类、要在同类细分图型之间二选一时读本文件。每条写法：**图型**（英文名）：它编码什么；什么情况下选它而不选相邻图型。

## 一、软件与系统架构（静态结构）

- **产品架构图 / 业务架构图**：自上而下分层的能力域、触点与外部依赖。读者是业务方、要看「能做什么」时选它；要看技术组件时换技术架构图。
- **功能模块图 / 功能分解图**：树状或卡片分组的子系统与功能点。讲范围与拆分时用；要看模块间调用时换组件图或依赖图。
- **技术架构图 / 应用架构图**：网关、服务、中间件、存储的分层与核心调用。只画核心调用，全量调用交给依赖图。
- **部署架构图 / 物理拓扑图**：可用区、节点集群、主从复制、容灾边界。讲「跑在哪、挂了切到哪」时选它。
- **网络拓扑图**：VPC、子网、路由、NAT、防火墙、负载均衡与流量路径。讲流量怎么进、怎么出、经过哪道安全组时选它；子网要标 CIDR。
- **C4 模型四层图**（Context / Container / Component / Code）：同一系统逐层放大。给零上下文读者先上 Context；每层只放大上一层的一个方框，不跨层混画。
- **微服务依赖图 / 服务网格图**：服务间调用拓扑与循环依赖。要找循环、扇入扇出时选它；边多时按层布局或改 DSM。
- **包图 / 模块依赖图**（Package Diagram）：代码目录、Monorepo 包、领域模块间的依赖方向。讲分层是否被违反时选它，违规依赖单独标色。
- **组件图**（Component Diagram）：组件及其提供 / 消费的接口（棒棒糖 / 插座记号）。重点是接口契约而不是调用顺序时选它。
- **集成架构图**：内外部系统经 API、MQ、Webhook、ESB 对接的全景。连线写协议与方向。
- **安全架构图 / 威胁建模图**：信任边界、鉴权链路、加密域；STRIDE 常配 DFD 记号。推演攻击路径换**攻击树**（Attack Tree）。
- **洋葱架构 / 六边形架构图**：同心圆分层，依赖只指向核心。讲依赖倒置与领域隔离时选它，不用来画运行时调用。
- **依赖结构矩阵**（DSM）：行列都是模块，格子表示依赖。模块多、边密时替代依赖图；下三角之外的格子就是反向依赖。

## 二、流程、交互与动态行为

- **业务流程图**（Flowchart）：节点、判断菱形、循环与起止。单一执行者、讲步骤与分支时选它。
- **跨职能泳道图**（Swimlane）：按角色、部门或系统分轨道。要点是职责交接、谁在等谁时选它。
- **BPMN 流程图**：事件类型、并行 / 排他网关、跨池消息流。要交给流程引擎执行、或跨组织协作要严格记号时选它；讲解用途泳道图更易读。
- **时序图**（Sequence Diagram）：生命线 + 消息箭头，区分同步 / 异步、返回与激活期。讲调用顺序、超时、重试时选它；参与方超过 7 个时拆图。
- **通信图 / 协作图**（Communication Diagram）：网状拓扑加编号消息。对象多、拓扑比先后更重要时选它。
- **状态机图**（State Machine）：状态、触发事件、守卫条件、复合状态、终态。对象生命周期、订单 / 工单状态流转选它。
- **活动图**（Activity Diagram）：并发分叉（Fork）、汇合（Join）、对象流。有并行步骤要汇合时选它而不选流程图。
- **用例图**（Use Case Diagram）：参与者、系统边界、include / extend。讲范围「谁能做什么」时选它，不表达顺序。
- **时序波形图**（Timing Diagram）：信号、总线或协议随精确时间轴的电平 / 状态跳变。时间刻度本身是重点（时钟、超时窗口）时选它。
- **事件风暴图**（Event Storming）：按时间轴排列命令、领域事件、聚合、策略便签。做领域建模工作坊、找聚合边界时选它，便签颜色按 Brandolini 约定。
- **决策树 / 故障树**（Decision / Fault Tree）：逐层条件分叉，或根因的与 / 或逻辑门。前者从条件推结论，后者从结果反推原因。

## 三、数据、存储与底层结构

- **ER 图**（实体关系图）：概念 / 逻辑 / 物理表结构与 1:1、1:N、N:M 乌鸦脚连线。讲表设计时选它；只讲关键实体时用概念层，别把全部字段铺上。
- **数据流图**（DFD）：外部实体、处理、数据存储之间的数据变换。讲数据怎么变，而不是谁调用谁；分层画时上下层的数据流要对得上。
- **数据血缘图**（Data Lineage）：表级或字段级的上下游加工依赖。排查「改这张表影响哪些报表」时选它。
- **数仓与 ETL 管道图**：ODS → DWD → DWS → ADS 分层与批流链路。列是分层、行是链路。
- **UML 类图 / DDD 领域模型图**：属性方法，继承、实现、组合、聚合、依赖。讲设计模式与对象职责时选它。
- **对象图**（Object Diagram）：某一时刻的具体实例与引用。讲「这一次内存里是什么样」时选它，类图讲的是可能性。
- **底层数据结构与内存布局图**：链表、红黑树、B+ 树、跳表、哈希槽、栈帧、对象头。讲算法或存储引擎内部时选它，标出一次查找的路径。
- **协议帧 / 封包位域图**（Packet / Bitfield Diagram）：按字节与比特切分报文。每行固定 32 位，字段宽度按位数等比。

## 四、AI、算法与现代工程

- **神经网络与模型架构图**：Transformer Block、注意力、残差连接与张量维度变化。在连线上标张量形状。
- **Agent 工作流与编排图**：ReAct 循环、工具调用、条件路由、多 Agent 协作（DAG / 状态图）。有循环与条件路由时按状态机画，纯流水线按 DAG 画。
- **RAG / 上下文工程链路图**：解析、切块、向量化、混合检索、重排、记忆注入、生成。离线索引与在线查询分成两条链路。
- **CI/CD 流水线图**：构建、单测、安全扫描、灰度发布、质量门禁。并行 job 并排，人工门禁单独标出，可附各阶段耗时。
- **Git 分支流图**（GitGraph）：多分支提交、Merge、Rebase、Cherry-pick、Tag。讲分支策略或一次热修复怎么合回时选它。
- **链路瀑布图 / 火焰图**（Trace Waterfall / Flame Graph）：前者是一次请求的 span 耗时嵌套（横轴是时间），后者是 CPU 采样栈占比（横轴是占比、不是时间）。讲单次慢请求用瀑布图，讲整体热点用火焰图。

## 五、产品设计、体验与业务画布

- **用户旅程图**（User Journey Map）：横轴阶段，纵轴行为、触点、情绪曲线、痛点与机会。
- **服务蓝图**（Service Blueprint）：旅程下方叠交互线、可视线、前台 / 后台、支撑系统。要说明体验问题的后台根因时选它而不选旅程图。
- **用户故事地图**（User Story Mapping）：横向骨架是业务活动，纵向按 MVP 与迭代切片。排需求优先级与发布范围时选它。
- **页面流转图**（User Flow / Screen Flow）：界面缩略框加跳转分支。讲屏幕之间怎么跳；讲单屏布局换线框图。
- **信息架构图 / 站点地图**（IA / Sitemap）：导航层级与页面归属树。
- **低保真线框图**（Wireframe）：栅格、控件占位、基础排版，全灰阶。
- **商业模式画布 / 精益画布**：固定九宫格，单页浓缩价值主张、渠道、成本结构。
- **价值流图**（Value Stream Mapping）：流程中的增值时间、等待时间与信息流。讲「时间耗在哪、多少是等待」时选它。

## 六、项目管理、组织与时间线

- **甘特图**（Gantt Chart）：横轴时间、纵轴任务条，里程碑菱形与前置依赖线。
- **路线图 / 时间轴**（Roadmap / Timeline）：按季度、版本或年份展开的演进主线；Now / Next / Later 路线图只承诺方向不承诺日期。
- **PERT 图 / 关键路径图**（CPM）：任务网络，标工期、浮动时间、关键路径。讲「哪条链决定总工期」时选它而不选甘特。
- **工作分解结构**（WBS）：交付物与任务的树状拆解，子项加总等于父项。
- **组织架构图**（Org Chart）：实线直属、虚线矩阵汇报、委员会。
- **看板图**（Kanban Board）：按状态列排列的任务卡，可标 WIP 上限与阻塞。
- **RACI 权责矩阵**：任务行 × 角色列，标负责、审批、咨询、知情。直接写成 markdown 表格即可。

## 七、逻辑思维与分析框架

- **思维导图**（Mind Map）：中心主题向外辐射的树。发散整理用；节点间有交叉关系换概念图。
- **概念图 / 知识图谱**（Concept Map / Knowledge Graph）：多对多网状节点，每条边带语义谓词，连读成一句话。
- **四象限 / 矩阵图**（2×2 Matrix）：双轴划象限，如重要性 × 紧急性、BCG 矩阵、魔力象限、成本 × 价值。
- **金字塔图与漏斗图**（Pyramid / Funnel）：层级底座或逐级转化衰减。漏斗每层宽度要与数量成比例（数量级差大时取对数并注明）。
- **韦恩图 / 欧拉图**（Venn / Euler）：集合的交、并、包含。只有包含关系或部分区域为空时用欧拉图，不画不存在的区域。
- **因果回路图**（Causal Loop Diagram）：增强环（R）与调节环（B）。讲「为什么越改越糟 / 增长为什么停」这类反馈问题时选它。
- **鱼骨图 / 石川图**（Fishbone）：主干指向结果，鱼刺按维度（人、机、料、法、环、测或自定）归类原因。已证实的根因单独标出，已排除项变灰。
- **SWOT / TOWS**：优势、劣势、机会、威胁四格；TOWS 再交叉出四类策略。
- **Wardley 地图**：组件按可见度（纵轴）与演化阶段（横轴）落位，标演化移动与惯性。讲技术选型「自建还是买」时选它。

## 八、定量数据可视化（统计图表）

先定要比的关系，再在该行里挑：

| 关系 | 图型 | 怎么挑 |
|---|---|---|
| 比较与排序 | 柱状图（基础 / 分组 / 堆叠）、条形图、子弹图、哑铃图、棒棒糖图、坡度图 | 类别名长或类别多用横向条形；只比两个时点用哑铃或坡度图；对目标值看达成用子弹图 |
| 趋势与周期 | 折线图、面积图、堆叠面积图、河流图、阶梯图、K 线图 | 连续时间用折线；值在离散时刻跳变（配置、价格档）用阶梯图；开高低收四值用 K 线 |
| 占比与构成 | 饼图、环形图、旭日图、矩形树图、华夫饼图、财务瀑布图 | ≤5 类且只看大致份额才用饼 / 环；有层级用旭日或矩形树图；从起点经增减到终点用瀑布图 |
| 分布与统计 | 直方图、核密度图、箱线图、小提琴图、蜂群图、QQ 图 | 单组看形状用直方；多组对比用箱线或小提琴；点少要看每个点用蜂群；检验是否服从某分布用 QQ 图 |
| 关联与多维 | 散点图、气泡图、热力图、雷达图、平行坐标图 | 两连续变量用散点（第三维用气泡大小）；两个类别维度交叉用热力图（如星期 × 小时）；维度多于 5 用平行坐标，雷达图只适合少量对象 |
| 流量与关系 | 桑基图、和弦图、弧线图、力导向网络图 | 有方向、分阶段的流量用桑基；两两互流用和弦 |
| 地理空间 | 分级统计地图、点分布地图、迁徙飞线图、六边形热力图 | 按行政区汇总用分级统计（注意面积大不等于量大）；点太密用六边形聚合 |

数据图表的通用规则：纵轴从 0 起（折线看变化率时可例外并注明）；两个单位不同的指标（如延迟与成本）默认画成上下两张共用横轴的小图，双 Y 轴两条刻度可以任意缩放、容易造出假的交叉点，只在读者必须在同一位置对照两条线时才用；强调色只给一个要点。
