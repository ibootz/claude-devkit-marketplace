# 行业图型目录

两种情况读本文件：

- **话题本身属于该行业**：用该行业约定俗成的图与记号，读者认记号；只为讲解、不按制图标准画的，注明「示意，非标准图纸」。
- **想借某种编码**：SKILL.md「跨领域借法」表已列出常用借法，这里是它们的原型与更多候选。条目末尾的「借：」写这种编码在软件、业务话题里能借来讲什么。

## 九、建筑、室内与城市规划

- **建筑总平面图**（Site Plan）：地块红线、朝向、退距、绿化与周边关系。借：系统上下文——本系统在中间，周边是外部系统与边界。
- **平、立、剖三图**（Floor Plan / Elevation / Section）：水平切开看布局、正面看外观、垂直切开看层高与楼梯关系。借：剖面——沿一次请求把系统「切开」，只画被切到的层。
- **轴测图与爆炸分析图**（Axonometric / Exploded View）：无透视变形的立体图，把屋顶、楼板、结构柱逐层拉开。借：分层架构或协议栈逐层拉开讲。
- **节点详图 / 大样图**（Detail Drawing）：1:5、1:10 放大施工死角。借：总图圈一处、旁边放大，讲关键细节。
- **结构施工图**：基础、柱墙梁板配筋，标钢筋型号、间距、混凝土强度。
- **机电施工图**（MEP）：给排水管网、强弱电点位与控制回路、暖通风管。借：多套管线叠在同一底图上，各用一种线型——多条链路（数据、控制、监控）叠画。
- **场地物理与行为分析图**：日照热力、风环境模拟、人车动线、视线廊道。借：动线图——用户或流量在空间（页面、系统）中的主要路径。
- **彩平图与渲染效果图**：面向甲方的材质填充平面与照片级效果图。

## 十、机械制造、工业设计与航空航天

- **机械三视图**（Orthographic Projection）：主、俯、左视图，长对正、高平齐、宽相等；中欧用第一角投影，美日常用第三角。借：同一对象从三个视角各画一张、互相对齐（如同一服务的部署视角、调用视角、数据视角）。
- **零件图**（Part Drawing）：尺寸公差、形位公差（GD&T）、表面粗糙度。指令图的典型：每个记号都有确定含义。
- **装配图与 BOM 爆炸图**（Assembly / Exploded View）：零件相对位置、配合、拆装顺序，序号气泡对应物料清单。借：图上编号、旁边列表——依赖清单、组件清单。
- **剖视图与局部放大图**：全剖、半剖、阶梯剖、旋转剖，暴露内部孔洞与油路。
- **钣金展开图**（Flat Pattern）：三维折弯件摊平，标折弯线与 K 因子。借：把环形或立体结构摊平成一条（如环形缓冲区、一致性哈希环展开）。
- **气动与液压原理图**：ISO 符号的泵、阀、气缸与回路。借：带阀门的回路——限流、熔断、背压在链路上的位置。
- **工业设计草图与人机尺寸图**：透视手绘、CMF 定义板、人体百分位操作包络。

## 十一、3D 建模、CG、影视与游戏开发

- **角色 / 道具三视图设定稿**（Model Sheet / Turnaround）：正、侧、背等比对齐。
- **拓扑布线图**（Topology Sheet）：四边面循环走向，检验动画变形。
- **UV 展开图**（UV Layout）：三维网格剪开摊平到 0–1 坐标系。
- **PBR 纹理贴图集**：漫反射、法线（紫蓝色凹凸）、粗糙度、金属度、AO、高度图，用颜色通道编码物理量。借：用颜色通道编码不可见的量（热力、权重）。
- **骨骼权重热力图**（Skin Weight Map）：红—黄—蓝渐变表示骨骼对顶点的影响权重。借：影响力热力——某个配置或服务对各模块的影响程度。
- **节点着色器图**（Shader Graph）：连线节点表达运算与纹理混合。借：数据处理管道的节点式表达（类似 DAG 编辑器）。
- **关卡白盒图与玩家热区图**：俯视动线、掩体视线、死亡 / 停留密度热力。借：页面点击热区、功能使用密度。
- **分镜头脚本与机位图**（Storyboard / Camera Blocking / Lighting Plot）：连环画式规定景别运镜；俯视片场标机位、走位与灯光。借：分镜——把一次交互或演示按帧画出关键画面。
- **动画曲线图**（F-Curve）：横轴帧、纵轴数值，贝塞尔手柄调缓入缓出。借：参数随时间的变化曲线（灰度放量比例、限流阈值）。

## 十二、电子电气、半导体与流程工业

- **电路原理图**（Schematic）：忽略物理位置，用标准符号表示元件与电气连接。借：符号化拓扑——只保留连接、丢掉位置。
- **PCB 布局布线图**（PCB Layout / Gerber）：真实尺寸的多层走线、过孔、阻焊、丝印。Gerber 是给机器读的图。
- **芯片版图**（IC Layout / GDSII）与**晶圆良率图**（Wafer Map）：前者是光刻掩膜图层；后者在圆形晶圆上按格标良品与缺陷。借：良率图——在固定版面上按格标通过 / 失败（如批量任务、多租户巡检结果）。
- **工业自控与电力图**：强电单线图（SLD）、二次控制回路、PLC 梯形图（Ladder Diagram）。借：梯形图——条件串并联决定输出，适合讲规则引擎的条件组合。
- **化工工艺流程图**（PFD）与**管道仪表图**（P&ID）：P&ID 标出每台设备、管道口径材质、阀门类型、温压液位控制回路。借：带仪表的流程——在流程节点上标监控点与控制回路。

## 十三、自然科学、医学与数学

- **医学与生物学**：人体系统解剖图（分层）、临床影像（X 光 / CT / MRI / 超声）、生理波形（ECG、EEG）、系统发育树、代谢通路图（KEGG）、染色体核型图、家族遗传系谱图（Pedigree）。借：进化树——版本或分支的演化谱系；代谢通路——多步转化网络与旁路。
- **化学与材料科学**：分子结构式与键线式、球棍 / 空间填充模型、相图（如铁碳相图）、反应势能曲线、波谱图（红外、NMR、质谱）。借：相图——两个参数组合下系统处于哪种状态（如并发 × 数据量下的「正常 / 降级 / 不可用」区域）；势能曲线——要越过的门槛（迁移成本）。
- **物理学与天文学**：受力分析图（Free-Body Diagram）、几何光路图、费曼图、电磁场矢量线、赫罗图、全天星图。借：受力分析——一个决定上作用的各方力量与方向。
- **数学与形式逻辑**：函数图像与极坐标图、扭结图、交换图（Commutative Diagram）、卡诺图（Karnaugh Map）。借：交换图——两条路径结果必须一致；卡诺图——检查布尔条件组合是否覆盖完全。

## 十四、地理、测绘、航海与航空

- **地形等高线图**（Topographic Map）：闭合曲线的疏密表达坡度与高程。借：二维连续量的等值线（如延迟随两个参数的变化）。
- **地质剖面图与地层柱状图**：岩层倾角、断层、褶皱、矿脉。借：地层——历史遗留按年代堆叠的层（代码或数据的沉积层）。
- **气象天气图**：等压线、锋面符号、等温线、风羽、台风概率路径、雷达回波。借：概率路径锥——预测的不确定性随时间扩大。
- **海图**（Nautical Chart）：水深点、等深线、暗礁沉船、灯塔射程、分道通航、潮流。借：标出暗礁——在路径图上标已知风险点。
- **航图**（Aeronautical Chart）：航路代号、最低安全高度、限制区、进离场程序（SID / STAR）、进近剖面。借：程序图——起止固定、中间分段带约束的标准路径（发布流程、应急预案）。
- **轨道交通拓扑图**（Transit Map）：1931 年伦敦地铁图范式，放弃真实距离，只留站点顺序、换乘与 45° / 90° 折线。借：服务调用路径总览、学习路径、多条业务线共享节点。

## 十五、服装、手作与生活工艺

- **服装纸样与推板图**（Sewing Pattern）：真实尺寸的二维裁片，标省道、缝份、纱向与多尺码套号。借：套号——同一模板在多个规格下的差异叠画（多环境配置差异）。
- **服装款式图**（Flat Sketch）：平铺线稿，标明线针距、纽扣位置、拼接工艺。
- **编织图解**（Knitting / Crochet Chart）：专用符号按行 / 圈排布。借：网格符号图——每格一个记号，按行读出操作序列。
- **折纸折痕图**（Crease Pattern）：展开成正方形，只用山折线（实线）与谷折线（虚线）编码全部折法。借：用两种线型编码两类操作。
- **装配步进说明书**（如家具、积木说明书）：无文字、逐步的零件清单、对齐方向与防呆警示。借：操作指南按步配图，每步只画该步新增的东西。

## 十六、音乐、体育、军事、法律与人文

- **音乐与舞蹈**：五线谱、简谱、吉他六线谱（TAB）与和弦指法图、音频波形与时频谱图（Spectrogram）、拉班舞谱（Labanotation）。借：多声部谱——多条并行轨道在同一时间轴上对齐（多个服务的事件对齐）；时频谱——横轴时间、纵轴频率、颜色强度。
- **体育与棋牌**：战术板阵型与跑位箭头、投篮命中率热区、球道攻略图、棋谱。借：战术板——各角色的起点、移动路线与配合时机。
- **军事与公共安全**：军标态势图（番号、钳形攻势箭头、防线、火力覆盖圈）、消防疏散路线图。借：覆盖圈——各节点的服务或监控覆盖范围与盲区。
- **金融、法律与人文**：股权穿透图（实控人追踪）、反洗钱资金流向图、案件人物关系网、历史疆域变迁图、族谱、叙事弧线图（Story Arc）。借：穿透图——层层持有关系追到最终归属（权限继承、配置覆盖链）；疆域变迁——同一版面多个时期对比（系统边界演进）。

## 十七、平面设计、印刷包装与视觉艺术

- **包装刀模图**（Die-line）：盒型摊平，用不同颜色与线型区分裁切、压痕、撕拉、出血、糊口。借：同一张图里用线型区分多类操作。
- **印刷拼版折手图**（Imposition Diagram）：大纸正反面如何排页，折叠裁边后页码连贯。借：映射关系——逻辑顺序与物理位置不同时，画两者的对应（分片、分区映射）。
- **色彩空间与色域图**：CIE 1931 色度图、孟塞尔色立体、色轮。
- **字体结构解剖图与字形网格**：基线、x 字高、升部 / 降部、汉字中宫重心。
- **品牌标识制图网格**（Logo Construction Grid）：圆形切线、黄金分割、最小安全留白。
- **绘画构图与透视网格**：一点至五点透视、黄金螺旋、明度小稿（Value Study）。

## 十八、交通工程、铁路调度与市政基建

- **列车运行图**（Train Diagram / Marey 图）：横轴 24 小时，纵轴沿线车站里程，每列车一条斜线；斜率是车速，水平段是停站，交叉是会车或越行。借：多个对象沿同一串阶段随时间推进——批任务各阶段、请求穿过多个服务、消息重试；平段就是排队。
- **绿波带时距图**（Time-Space Diagram）：时间—距离坐标规划连续红绿灯的相位差。借：周期性窗口的错峰与对齐（定时任务、限流窗口）。
- **车辆扫掠路径包络图**（Swept Path Analysis）：车辆转弯时车身外缘扫过的边界。借：一次变更或故障的影响包络。
- **路口渠化与流量流向图**：用不同粗细的弯箭头标各方向车流量与冲突点。借：线宽表示流量的流向图（接口流量分布）。
- **综合管廊横断面图**：电力、通信、给水、燃气等在地下空间的排布与安全净距。借：资源隔离——各类负载在共享资源里的排布与隔离边界。

## 十九、经济学、金融工程与供应链物流

- **经济学理论模型图**：供需曲线、无差异曲线、生产可能性边界（PPF）、IS-LM、洛伦兹曲线、拉弗曲线。借：PPF——两个目标此消彼长的取舍边界（性能 × 成本）；洛伦兹——集中度。
- **博弈论图示**：扩展式博弈树、收益矩阵。借：多方决策的先后与得失。
- **金融衍生品损益图**（Payoff Diagram）：横轴到期价格、纵轴盈亏的折线，表达期权及组合策略的风险敞口。借：策略在不同输入下的得失，拐点即阈值。
- **交易市场微观图**：订单簿深度图（买卖挂单累计墙）、收益率曲线、资金流向树。借：深度图——供需两侧的累计对冲。
- **会计与财务图**：T 型账户、杜邦分析拆解树、合并报表抵消图。借：杜邦树——一个指标逐层拆成乘积因子（转化率 × 客单价 × 流量）。
- **物流配载与码垛图**（Palletization / Container Loading Plan）：托盘或集装箱内的三维堆叠。借：资源装箱——实例、容器如何装进节点。

## 二十、语言学、哲学、心理学与社会学

- **语言学**：句法树（Syntax Tree）、依存句法弧线图、元音舌位梯形图、发音器官剖面图、语系谱系树。借：依存弧线——一条序列上元素之间的依赖（token、日志行、事件之间的引用）。
- **哲学与逻辑**：逻辑对当方阵（Square of Opposition）、论证图谱（Argument Map，区分前提、结论、反驳、补强）、格雷马斯方阵。借：论证图谱——方案拍板的依据与反驳。
- **心理治疗家系图**（Genogram）：形似族谱，但用锯齿线、双实线、虚线编码冲突、紧密纠缠、断联与代际模式。借：用线型编码关系的质量，而不只是有无。
- **社会计量图**（Sociogram）：有向边表示喜爱、排斥，显出孤立者与意见领袖。借：协作网络中的关键节点与孤岛。
- **脑科学与情感模型**：布罗德曼分区图、连接组（Connectome）、普拉奇克情感轮。借：情感轮——环形排布的分类体系，相邻相近、相对相反。
- **心理测验与知觉图**：罗夏墨迹、格式塔完形法则图、石原氏色盲图、视错觉图。借：石原氏图提醒配色——红绿不能是唯一区分手段。

## 二十一、农林牧渔、植物学与生态学

- **植物花图式**（Floral Diagram）：极坐标同心圆与标准符号，一张平面图记录花萼、花瓣、雄蕊、雌蕊的数目、排列与合生。借：极坐标符号图——紧凑表达环形对称的组成。
- **土壤质地三元相图**（Soil Texture Triangle）：三边是砂、粉、黏粒百分比，落点即类别。借：三个分量合计 100% 的构成分布。
- **生态与物种图**：能量金字塔、食物网、迁徙走廊、林相图（树种、林龄、郁闭度）。借：食物网——谁消费谁的多对多依赖。
- **畜牧与烹饪分割图**：全身部位分割与等级。借：把一个整体按区域切分并标等级（如代码库按模块标质量等级）。

## 二十二、古典文明、传统技艺与宗教宇宙观

- **古代长卷式舆图**（如郑和航海图）：把海岸线拉直成一字长卷，沿途写针路（航向）与更数（航程）。借：把曲折的路径拉直成一条线，沿线标关键节点——长链路的线性化表达。
- **传统建筑法式图样**：《营造法式》的正样、侧样、斗拱分解（材分制模数）。借：模数——用统一基本单位推导所有尺寸。
- **传统医学图谱**：经络穴位图、耳穴全息图、舌诊分区图、足底反射区图。借：分区映射——一块区域对应另一个系统的部分。
- **古典星象与历法图**：敦煌星图、星盘球极投影、二十四节气太阳轨迹、本命星盘。借：环形时间——周期事件排在一个圆上。
- **宗教与哲学宇宙观图**：曼荼罗（三维宫殿的俯视平面）、T-O 地图、神曲九层地狱剖面、河图洛书与六十四卦方圆图。借：同心层级——由核心向外逐层展开。
- **传统武术与礼仪图**：拳谱步法轨迹、礼乐站位与阵法图。

## 二十三、休闲技艺、桌游兵推与交互叙事

- **魔方公式状态图**（OLL / PLL）：顶层九宫格色块加置换箭头，一图编码一套手法。借：状态加置换箭头——一个操作如何重排元素（如数据迁移的重分片）。
- **绳结拓扑图**（Knot Diagram）：绳股的上下压穿、穿插顺序与拉紧方向。
- **互动叙事分支树**（Branching Narrative Flowchart）：剧情节点、条件变量锁、多结局收敛。借：多分支对话流、引导流程、A/B 路径。
- **战棋六角格兵推图**（Hex Map）：六边形网格消除对角线距离误差，叠加地形修正。借：六边形聚合——点太密时的空间分箱。
- **漫画分镜与阅读动线图**：格框大小、留白、气泡排列控制眼动节奏。借：图解与幻灯片的阅读顺序设计。
- **益智解谜图**：迷宫、数织、桥谜、逻辑推理网格。借：推理网格——多个属性两两排除（排查时的条件交叉排除表）。

## 二十四、非人类视角、数学自生成与特种传感成像

这一类多数不是画给人看、或不是人画的，选型时用来判断「这张图的读者是不是机器」：

- **机器可读编码图**：条形码、QR 码、DataMatrix、Aztec 码、胶片光学声轨——面向光学传感器的高容错位图。
- **特种物理传感成像**：LiDAR 点云、超声相控阵探伤（B-Scan / S-Scan）、红外热成像、电子显微镜图。借：热成像——一眼找出「发烫」的部件。
- **数学迭代自生成图**：分形（曼德勃罗集、茱莉亚集）、元胞自动机时空图、洛伦兹吸引子相空间轨迹。借：时空图——横轴位置、纵轴时间，每行是一代状态（逐轮传播、扩散过程）。
- **物理规律自发成图**：克拉尼图形（沙粒在驻波波节聚成对称纹样）。
- **视觉加密与光学图**：裸眼立体画、莫尔条纹、视觉密码分存图。
