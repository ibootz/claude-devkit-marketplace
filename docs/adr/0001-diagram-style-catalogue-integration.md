# ADR 0001：外来「全域图谱与风格引擎」怎么并进现有绘图 skill

编制：2026-11-22，用户在会话里逐题拍板（Q1-a、Q2-a、Q3）。
读者假定：懂开发，不了解本仓绘图链路。

**一句话：不新建 skill，把那份规范拆进现有三个绘图 skill；风格默认仍是 `mac`，渲染器补技术图布局，并加一个自由坐标兜底模式，兜底时同样走主题配色。**

---

## 背景

用户带来一份 AI 生成的 SKILL.md 规范，内容包括：24 类图型、Zone 0/1/2 安全区、T1–T8 拓扑、S01–S20 二十种视觉风格（每种 6 个 token）、CSS/SVG 配方、6 条自检。

本仓现有的绘图链路：

| 环节 | skill | 管什么 |
|---|---|---|
| 判断该不该画 | devkit-discipline 每轮注入的「画图」规则 | 命中就调 show-me |
| 选视图、载体、落点 | `devkit-tool:show-me` | 用伪代码、表格还是成品图，图放在哪 |
| 选图型 | `devkit-tool:diagram-types` | 选哪种专业图 |
| 渲染成品图 | `devkit-svg-diagram:svg-diagram` | JSON 描述 → `render.py` → SVG/PNG，固定主题 |
| 点名才用 | `devkit-excalidraw-diagram` | 可拖拽改的 `.excalidraw` 白板图 |

规范里大部分内容和上面这些 skill 重叠：24 类图型在标题层面与 diagram-types 的 software.md、cross-domain.md 对得上（条目层面没逐条比）。真正新增的只有风格目录和拓扑分类两样。

## 决定

**Q1-a 风格默认不变。**
默认仍用 `mac`，用户点名才换别的。
S01–S20 风格目录写进 [`svg-diagram/references/styles.md`](../../plugins/devkit-svg-diagram/skills/svg-diagram/references/styles.md)，只在用户点名某种风格、或问有哪些风格时查。
不做按图型自动选风格。

**Q2-a 只新增两套主题。**
S01（黑白加单一强调色）、S03（深色扁平，不做渐变描边和发光）。主题键名 `ligne`、`dark` 是实现时起的名字。
两套都必须实测渲染、过对比度检查（文字 ≥4.5:1，线条 ≥3:1）。
S01 做不到让十个 role 彼此可区分时就放弃这套。role 是卡片的语义角色，比如主流程、AI、平台、外部系统，每个主题给这十个 role 各配一组颜色。
现有 `swiss` 实际就是 S12（包豪斯），不改名。

**Q3 补技术图布局，没有预制布局时用自由坐标兜底。**
`render.py` 新增 `tree`（组织架构、WBS、决策树）、`lanes`（泳道）、`tasks`（甘特、时间线）、`entities`（ER、类图）、`matrix`（四象限）五种布局。
上面都画不了的图用 `canvas` 自由坐标模式：每个元素自带 x/y/w/h。
用户追加了一条约束：**自由坐标也走主题的 role 配色，默认 mac，用户点名才换**，spec 里不允许写死颜色。

**顺带的两处小改：**
- diagram-types 的选型结论多写一项「拓扑」，交给渲染器挑布局。
- diagram-types 加一条规则：指令图（规格、排期、施工图）换风格时只改载体层（底色、线宽、字体），记号与比例保持行业规范。

## 没采纳的

- **按图型自动路由风格**：会让同一份文档里的图风格不一致，和「一篇文档一套主题」冲突。
- **规范 §3 每类图配哪几种风格的那几列**：依赖自动路由，跟着一起不采纳。
- **拓扑 × 风格冲突检查**：现有主题组合里找不到会冲突的情况，加了也查不出东西。
- **把 CSS 配方写进 SKILL.md**：样式全部由 `themes.json` 决定，SKILL.md 里写配方等于有了两处来源。
- **画不了就转 Excalidraw**：和「点名才用 Excalidraw」冲突，改由 `canvas` 兜底。
- **T8 数据图表**：不放进 svg-diagram；去向未定。

## 后果与未核实

- show-me 现在的路由是：有预制布局就用预制布局；没有就用 `canvas`；只有用户点名 Excalidraw 才走 Excalidraw。
- **已实测（2026-11-22）**：`ligne`、`dark` 都保留，对比度检查 0 项不达标。`ligne` 用五档底色（白、浅灰、中灰、黑、蓝色强调）加五种线型（细实、粗实、长虚、强调色短虚、点线）区分十个 role，在灰度渲染下逐一核对过。
- **未核实**：规范的 24 类图型与 diagram-types 只在标题层面对过。要确认有没有漏掉的图型，得逐条比对两边的条目。

**重开条件**：用户要求自动选风格；或者有三种以上点名风格因为缺渐变、滤镜、纹理画不出来，那时再考虑扩展渲染器能力。
