# ADR 0001: 取整发生在单价层，不在总价层

Status: accepted

## Context

购物车总价计算涉及折扣，折扣后的金额需要取整到分。取整可以发生在两处：
（a）每个商品单价打折后取整，再乘数量求和；（b）先求原始总价，打折后对总价统一取整一次。

## Decision

选 (a)：取整发生在单价层。理由是发票要求逐行金额本身就是"分"精度，取整放到总价层会导致
发票逐行金额加总与显示总价对不上。

## Consequence

各商品行取整到分之后再乘数量、求和，结果理应天然是分精度整数——总价层再对结果做一次
`Math.round` 在数学上是多余操作，不是本决策要求的一步。
