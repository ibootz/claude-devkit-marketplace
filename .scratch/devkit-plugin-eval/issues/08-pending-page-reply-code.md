# 08 — 待审页与回复码

Status: ready-for-agent

**What to build:**

所有人工环节集中在一个本机生成的 HTML 待审页：每次对照一页、每次复盘一页。本票先打通「报告审阅」这一环，并把待审项做成可扩展的类型，供 09（分歧样本、抽检）、10（条款清单变更）、11（用例草稿）、12（复盘候选）往里加项。

用户在页上选完，复制回复码贴回对话；CLI 解析回复码，把裁定写回 `run.json`（审阅状态改「已审」、记审阅时间）及相应文件。每页 ≤ 10 个待判项，超出时自动抽样，并在报告里写明抽了哪些。待审页不入库。

**Blocked by:** 03


- [ ] 对一次对照生成待审页，页上能看到报告摘要并勾选「已审」；贴回回复码后 `run.json` 变为已审并带审阅时间
- [ ] 回复码格式错误或对不上该次运行时，CLI 报错且不改任何文件
- [ ] 构造超过 10 个待判项时页上只出 10 项，报告写明抽样规则与被抽中的项
- [ ] 新增一种待审项类型只需注册类型与写回逻辑，不改页面框架（以一个示例类型证明）
- [ ] 改插件文件前按仓根 CLAUDE.md 先读规定的技能
